    Syntax reference

    Custom checks — one per line. on <pattern> narrows a rule to elements whose path or sheet key matches; the last two fields are severity and your own wording.

    forbid:  <pattern> [on <pattern>] [| high|medium|low] [| message]
maxlen:  <characters> [on <pattern>] [| severity] [| message]
casing:  upper|lower|title [on <pattern>] [| severity] [| message]
require: <pattern> on <pattern> [| severity] [| message]

    Setup steps — one per line, replayed in order. Coordinates from 0 to 1 are a fraction of the screen, so a script survives a different device; larger numbers are pixels. Anything after # is a comment.

    tap <x> <y>              longpress <x> <y> [ms]
swipe <x1> <y1> <x2> <y2> [ms]

    How this works.

    LocaLinter reads a localization sheet and points out the strings a player would see go wrong. Start by opening a sheet — everything else is a view onto it.

    The four sections

    Format issues
    Translated text whose brackets, spacing or {variables} no longer match the English original — the errors that show up in-game as a literal {0} or a broken tag.
    Missing locales
    Keys that have English copy but an empty cell in one or more languages, so the game falls back to English for those players.
    Search
    Free text search across every column of the sheet. The gear beside the box switches between contains, exact, whole-word and regular-expression matching, and lets you narrow to one column.
    Device scan
    Runs your actual build — on a phone over USB, or in the Unity Editor — walks its screens and compares the text on them against the sheet. Needs a one-time Anthropic API key.

    Working with results

    • Cells from a Google Sheet are editable in place: click one, type, press Enter. The change is written back to the sheet.
    • Ctrl+Z undoes the last cell you saved.
    • Double-click any cell to copy its contents.
    • Wrap in the toolbar shows long strings in full instead of scrolling sideways.
    • Keys you never want checked go in Settings → Ignored terms.
