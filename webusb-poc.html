WebUSB ADB.

Proof of concept: talk to the phone straight from this page, with no local agent. The page claims the device's ADB USB interface, speaks the ADB wire protocol itself, and signs the auth challenge in JavaScript. Nothing here contacts a server — open DevTools' Network tab and watch it stay empty.

Before you connect: a running adb server holds the USB interface exclusively and Chrome cannot claim it. Run adb kill-server in a terminal first. Chromium-based browser required (Chrome or Edge) — WebUSB does not exist in Firefox or Safari.
